# Metadane aktualizacji linkorder

Repozytorium TUF (The Update Framework) z podpisanymi metadanymi wydań linkorder, serwowane jako strona
statyczna. Pliki zapisuje wyłącznie potok wydań — nie edytuj ich ręcznie: każda zmiana bez podpisu
właściwych kluczy zostanie odrzucona przez instalator na serwerze.

Katalog propozycje/ zawiera niepodpisane propozycje wydań czekające na podpis właściciela.
